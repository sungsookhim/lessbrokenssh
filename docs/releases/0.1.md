lessbrokenssh 0.1 is the first release of this fork of [ssheven](https://github.com/cy384/ssheven) 0.9.0, an SSH client for Mac OS 7, 8 and 9. The goal is to run modern full-screen terminal programs, like the Claude CLI and btop, from a classic Mac without the screen breaking apart.

## Downloads

| File | For |
|---|---|
| `lessbrokenssh-0.1-68020.bin` | any 68k Mac with a 68020 or 68030 (Mac II family, LC, LC II, LC III, IIci, SE/30) |
| `lessbrokenssh-0.1-68040.bin` | 68040 Macs (Quadra, Centris, LC 475, LC 575) |
| `lessbrokenssh-0.1-g3.bin` | any PowerPC Mac (601, 603, 604, G3, G4); tuned for the G3 |
| `lessbrokenssh-0.1.dsk` | an HFS disk image with all three apps and a Read Me, for emulators and disk-image tools |

The `.bin` files are MacBinary: decode them on the Mac with StuffIt Expander, or transfer them with a tool that understands MacBinary. Only one app is needed. The 68020 app also runs on a 68040, just tuned less well.

Tested on an iMac G3 (Mac OS 9, `g3`) and an LC 475 (`68040`). The `68020` build hasn't been tried on a 68020 or 68030 Mac yet.

## Requirements

- System 7.1 or later (below 7.5, the Thread Manager extension)
- Open Transport
- 4 MB of free memory (3 MB minimum)
- No FPU needed

Settings live in `lessbrokenssh Preferences` and `lessbrokenssh known_hosts`, apart from ssheven's, so the two apps can be used side by side.

## What's new compared with ssheven 0.9.0

| | ssheven 0.9.0 | lessbrokenssh 0.1 |
|---|---|---|
| Box drawing, blocks, shades, Braille, sextants, Powerline | `◊` | real glyphs (500+, 6×12) |
| Symbols (`⏺ ⎿ ✻ ❯ ✓ ☐ ↑ ⌘`…) | `◊` or `b` | hand-drawn glyphs |
| Latin-1 and Mac Roman (`é ß © ° · … • – —`) | ASCII lookalikes | the real characters |
| Emoji | `◊` | a selected 256 of Unicode's emoji, in color (8-bit, 4-bit and dithered black-and-white) |
| Japanese, Korean, Chinese | `◊` | the system's own fonts, when those scripts are installed |
| Wide characters and emoji | line shifts by a column | correct widths (Unicode 16, emoji with VS16) |
| Colors | 8 colors, `TERM=xterm-16color` | 256-color and truecolor on 4-bit and deeper screens, `TERM=xterm-256color` |
| Scrollback | none | 1,000 lines with a scroll bar and Shift-Page Up/Down |
| Keys and mouse | Shift-Tab sends Tab; clicks only in the basic mouse mode | Shift-Tab sends back-tab; clicks in any mouse mode (Shift-click selects text) |
| Responsiveness | redraws the whole screen and sleeps ~130 ms between network checks | redraws only changed rows and checks the network every tick |

Also fixed: the port typed in the connect dialog was dropped by upstream's unreleased code, so connecting failed. There's a new icon too.

## Keys worth knowing

| Keys | Does |
|---|---|
| Shift-Page Up / Shift-Page Down, or the scroll bar | scroll lessbrokenssh's history |
| Page Up / Page Down | go to the program |
| Option-Return | Meta-Return; a new line in the Claude CLI's input instead of sending |
| Shift-Tab | back-tab; cycles the Claude CLI's modes |
| Esc | Escape; interrupts the Claude CLI |
| Shift-click | selects text even when the program uses the mouse |

## Known gaps

- **CJK needs the system's language kits.** Without them (like an English System 7.6), Korean and Japanese show `◊`. Hangul syllables outside the 2,350 in KS X 1001 also show `◊`.
- **Ed25519 keys** don't work, since this libssh2 build has them turned off. RSA and ECDSA keys work.
- **Truecolor** needs `AcceptEnv COLORTERM` in the server's sshd, or `export COLORTERM=truecolor` in your shell profile there.
- **btop is slow on the LC 475.** Setting `update_ms` to 4000 or more, `truecolor = False` and a flat theme like `TTY` helps. top and htop run fine.
- **Text you copy or type leaves the Mac as Mac Roman,** not UTF-8.
